# ⏱️ Time Converter

A simple C++ program that converts time between **seconds** and **HH:MM:SS** format using a class and menu-driven approach.

---

## 📚 Program

### Q1 — Time Converter

The program provides two conversion options:

- Seconds → HH:MM:SS
- HH:MM:SS → Seconds

### Example

```text
1. Seconds to HH:MM:SS
2. HH:MM:SS to Seconds

Enter your choice: 1
Enter Total Seconds: 4200

HH:MM:SS => 1:10:0
```

```text
Enter your choice: 2
Enter Hours: 4
Enter Minutes: 34
Enter Seconds: 30

Total Seconds: 16470
```
